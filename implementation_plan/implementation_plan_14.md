# Tahap 14 — Frontend Reports, Budget, Chat, dan Penyempurnaan UX

## Tujuan
Menyelesaikan fitur P1 dan memenuhi target performa, accessibility, serta responsive behavior.

## Langkah
1. Buat summary cards, period picker, grafik SVG, dan tracker contributions.
2. Buat budget meter dan form.
3. Buat activity feed dan export controls.
4. Buat chat thread, message bubble, table block, consent, quota, dan unavailable state.
5. Terapkan lazy loading dan optimasi aset.
6. Audit target sentuh 44 px, fokus keyboard, reduced motion, contrast, dan error states.
7. Ukur bundle size, LCP, INP, CLS, dan Lighthouse mobile.

## Verifikasi
Semua P1 route bekerja, grafik memiliki alternatif teks, chat read-only, Lighthouse mobile ≥85, dan target Core Web Vitals tercapai atau deviasinya terdokumentasi.

## Dependensi

## Output
Frontend P1, accessibility polish, performance report, dan UX error/empty/loading states.
