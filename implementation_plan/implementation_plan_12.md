# Tahap 12 — Frontend Fondasi dan Autentikasi

## Tujuan
Membuat SPA mobile-first dengan routing data mode dan sesi aman.

## Langkah
1. Buat `createBrowserRouter`, root loader, lazy routes, dan error boundary.
2. Buat typed API client dengan CSRF, timeout, retry GET, dan `ApiError`.
3. Generate tipe dari OpenAPI.
4. Buat `SessionContext`, public layout, app shell, bottom nav, dan desktop gate.
5. Buat login, register, logout, account, dan error states.
6. Terapkan viewport mobile, Bahasa Indonesia, accessibility dasar, dan safe area.

## Verifikasi
Unit test API/session/formatting, redirect aman, login/register/logout E2E, keyboard navigation, dan frontend build.

## Dependensi
`implementation_plan_10.md` serta kontrak OpenAPI.

## Output
SPA foundation, authentication UI, API client, routing, dan component baseline.
