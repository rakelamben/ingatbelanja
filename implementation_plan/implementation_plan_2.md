# Tahap 2 — Fondasi Proyek dan Tooling

## Tujuan
Membuat proyek backend/frontend yang dapat dipasang, diperiksa, dites, dan dijalankan ulang.

## Langkah
1. Buat `backend/`, `frontend/`, `storage/`, `tasks.py`, `.env.example`, `.gitignore`, `.python-version`, dan lisensi Apache-2.0.
2. Siapkan venv Python dan dependency versi pin.
3. Buat React + TypeScript + Vite + Tailwind CSS v4.
4. Konfigurasi Ruff, pytest, ESLint, Prettier, Vitest, dan Playwright.
5. Buat konfigurasi `pydantic-settings`.
6. Implementasikan command `setup`, `doctor`, `test`, `build`, dan `dev`.

## Verifikasi
Proyek kosong berhasil setup, lint, type-check, test, frontend build, dan doctor tanpa error kritis.

## Dependensi
`implementation_plan_1.md` dan hasil spike.

## Output
Fondasi repo yang dapat dijalankan dari Windows 11.
